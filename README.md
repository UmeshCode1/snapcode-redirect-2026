# SNAPCODE 2026 Registration Redirect Page

This is a modern, professional, highly animated event landing page for the AI & Machine Learning Club, Oriental College of Technology (OCT), Bhopal.

## Features

- **Framework**: React (Next.js App Router)
- **Styling**: Tailwind CSS v4 with custom glassmorphism and modern AI-themed designs.
- **Animations**: Integrated with Framer Motion for smooth scroll effects and page transitions.
- **Auto-Redirect**: Features a built-in 5-second countdown that automatically redirects to the Tally registration form.
- **Responsive**: Fully responsive design for mobile, tablet, and desktop devices.
- **SEO Optimized**: Standard metadata configured.

## Running Locally

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Deployment Instructions

To deploy this project to GitHub and subsequently to Vercel/Netlify, run the following commands in your terminal:

```bash
git init
git add .
git commit -m "Initial SNAPCODE 2026 landing page"
git branch -M main
git remote add origin <repository-url>
git push -u origin main
```

Replace `<repository-url>` with your actual GitHub repository URL.

### Custom Domain Support
This application is ready to be hosted and connected to custom domains such as:
- `event.aimlclub.tech`
- `snapcode.aimlclub.tech`

Simply add the domain in your Vercel or Netlify dashboard and update your DNS records accordingly.
